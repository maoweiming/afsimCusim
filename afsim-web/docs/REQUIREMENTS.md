# TrueSim 系统需求文档

## 1. 系统概述

### 1.1 定位

TrueSim 是将 AFSIM（Advanced Framework for Simulation, Integration, and Modeling）军事仿真框架改造为可通过浏览器访问的云原生仿真服务平台。核心原则：**不修改 AFSIM 引擎**，仅在外层构建网关和 Web 前端。

### 1.2 目标用户

| 角色 | 描述 | 典型任务 |
|------|------|---------|
| 指挥员（admin） | 完全访问权限，系统管理 | 想定管理、仿真控制、装备维护、数据分析 |
| 参谋（operator） | 仿真操作和想定管理 | 仿真操控、想定编辑、装备查询 |
| 技术员（analyst） | 数据分析和地形评估 | 地形分析、数据导出、态势研判 |
| 观察员（viewer） | 只读查看态势 | 态势监视、事件查看 |

### 1.3 核心价值

- **云原生**：浏览器即可访问，无需安装本地客户端
- **插件化**：按角色动态加载功能模块，降低认知负担
- **实时性**：WebSocket 推送仿真事件，100+ 实体流畅渲染
- **可扩展**：插件/图层/数据源均可自定义扩展
- **协同编辑**：支持 15+ 人同时编辑想定，OT 操作转换 + 分支管理

## 3. 非功能需求

### 3.1 性能需求

| 需求 ID | 需求描述 | 指标 |
|---------|---------|------|
| NFR-001 | 大量实体渲染 | 100+ 实体 @ 30fps |
| NFR-002 | WebSocket 消息处理 | 支持 20 msg/s 持续吞吐 |
| NFR-003 | 页面首屏加载 | < 3s（代码分割后主 chunk 33kB） |
| NFR-004 | 图层切换响应 | < 200ms |
| NFR-005 | 事件查询延迟 | < 500ms（5000 条事件内） |

### 3.2 可用性需求

| 需求 ID | 需求描述 | 指标 |
|---------|---------|------|
| NFR-010 | WebSocket 断线重连 | 指数退避，最多 10 次重试 |
| NFR-011 | API 请求重试 | 5xx 错误自动重试 3 次 |
| NFR-012 | 请求超时 | 30s 超时 + AbortController |
| NFR-013 | 错误收集 | 全局错误存储（最多 200 条） |

### 3.3 安全需求

| 需求 ID | 需求描述 |
|---------|---------|
| NFR-020 | 角色权限控制（4 级角色，插件级访问控制） |
| NFR-021 | 路由守卫（requiresAuth 标记） |
| NFR-022 | 想定密级标注（classification 字段） |
| NFR-023 | 对象锁定（防并发编辑冲突） |

### 3.4 可扩展性需求

| 需求 ID | 需求描述 |
|---------|---------|
| NFR-030 | 插件系统（PluginRegistry + BasePlugin，支持自定义插件） |

## 4. 数据需求

### 4.1 数据流概览

```
AFSIM引擎 → WSF插件(Observer回调) → 命名管道(Protobuf) → Go仿真网关 → WebSocket(JSON) → React前端
                                                                      ↓
                                                              数据中间平台（持久化）
                                                                      ↓
                                                              MongoDB / InfluxDB
```

### 4.2 前端数据架构

```
┌─────────────────────────────────────────────────────┐
│                    React 前端                        │
│                                                     │
│  ┌──────────┐  ┌──────────┐  ┌──────────────────┐  │
│  │ WebSocket │  │ REST API │  │ IndexedDB        │  │
│  │ 消息路由  │  │ 客户端   │  │ 本地持久化       │  │
│  └─────┬────┘  └────┬─────┘  └────────┬─────────┘  │
│        │            │                  │            │
│        ▼            ▼                  ▼            │
│  ┌─────────────────────────────────────────────┐   │
│  │          Zustand Stores (15+)               │   │
│  │  simStore / platformStore / trackStore /    │   │
│  │  weaponStore / eventStore / aiStore / ...   │   │
│  └─────────────────────────────────────────────┘   │
│        │                                            │
│        ▼                                            │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐         │
│  │ EventBus │  │ DataBus  │  │ Config   │         │
│  │ 发布订阅 │  │ 数据总线 │  │ Registry │         │
│  └──────────┘  └──────────┘  └──────────┘         │
└─────────────────────────────────────────────────────┘
```

### 4.3 持久化策略

| 数据类型 | 存储位置 | 说明 |
|---------|---------|------|
| 仿真事件 | IndexedDB | 本地持久化，支持按 simId 查询 |
| 图层配置 | localStorage | 序列化保存用户自定义图层覆盖 |
| 插件存储 | localStorage | 每个插件独立命名空间 |
| 引导状态 | localStorage | 新手引导完成标记 |
| 装备/想定 | 数据平台 | MongoDB 持久化 |
| 仿真回放 | 数据平台 | InfluxDB 时序存储 |

## 5. 集成需求

### 5.1 AFSIM 引擎接口

| 接口 | 协议 | 说明 |
|------|------|------|
| 事件推送 | 命名管道 `\\.\pipe\afsim_events` | Protobuf 编码，Observer 回调触发 |
| 控制指令 | 命名管道 `\\.\pipe\afsim_control` | Protobuf 编码，仿真控制命令 |
| 插件加载 | WSF DLL | C++ 插件，通过 WsfPluginManager 加载 |

### 5.2 仿真网关接口

| 接口 | 协议 | 端口 | 说明 |
|------|------|------|------|
| REST API | HTTP | 8080 | 想定管理、仿真控制 |
| WebSocket | WS/WSS | 8080 | 实时仿真事件推送 |
| 传感器控制 | REST POST | 8080 | `/api/simulations/:id/control/sensor-steer` |
| 武器发射 | REST POST | 8080 | `/api/simulations/:id/control/weapon-fire` |

### 5.3 数据中间平台接口

| 服务 | 协议 | 端口 | 说明 |
|------|------|------|------|
| data-gateway | REST | 8080 | 统一 REST API 入口 |
| equipment | gRPC | 50051 | 装备数据 CRUD |
| scenario | gRPC | 50052 | 想定数据 CRUD |
| timeseries | gRPC | 50053 | 时序数据查询（回放帧） |
| geospatial | gRPC | 50054 | 地理空间数据 |

### 5.4 第三方数据源

| 数据源 | 类型 | 接口 | 说明 |
|--------|------|------|------|
| OpenWeatherMap | 天气 | REST API | 风速、温度、气压、能见度 |
| NOAA | 潮汐/海情 | REST API | 潮位预测、海况等级 |
| Cesium Ion | 地形/影像 | SDK | 全球地形 + 卫星底图 |
| OpenStreetMap | 底图 | 瓦片 | 2D 矢量底图 |
